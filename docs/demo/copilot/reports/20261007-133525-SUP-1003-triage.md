## 🗺️ How It Works (and Where It Breaks)
The UI export serializes at most the first 10,000 rows of the current sort order. The table can show a larger total (48,212), so the two numbers disagree by design. Full data is available through the Query API with cursor pagination or the warehouse export.

## 🎯 Root-Cause Assessment
**Assessment:** 🎯 Documented 10,000-row cap on UI CSV export (tracked as feature request BEACON-097). Not a malfunction.
**Confidence:** Confirmed by data
**Reasoning:** The docs state the cap, and the observed count is exactly 10,000 against a larger table. The known-issue gate found the matching backlog item.
**Not explained:** Whether the export dialog showed the limit banner for this customer. Their plan's access to the warehouse export is unknown. Confidence is limited by lack of project data access, but the cause is documented.

## Recommended Next Action
🔧 Workaround: use the Query API with cursor pagination, or export March in date-range batches each under 10,000 rows. Check the plan for the warehouse export. Optionally note this customer's demand on BEACON-097 (human action; this agent is read-only).
