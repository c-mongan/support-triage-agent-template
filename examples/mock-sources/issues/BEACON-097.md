## Summary

Customers want to download more than 10,000 rows from the Insights table in a single CSV file. The UI export is capped at 10,000 rows today; the cap is documented.

## Current guidance

Use the Query API with cursor pagination for full exports, or narrow the date range and export in batches.

## Status

Open and accepted onto the backlog. No delivery date has been committed.
